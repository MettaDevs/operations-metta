## Resource pada katalog HTTP tanpa halaman profil tersendiri dalam snapshot

Appointment, AppointmentResponse, HealthcareService, PractitionerRole dan Slot memiliki operasi pada [katalog HTTP FHIR](../endpoint/inventaris-operasi-http.md#fhir-dan-orientasi). Alur, contoh payload dan pemetaan field dibahas di [Penjadwalan dan janji temu](../alur/penjadwalan-dan-janji-temu.md). Schedule disebut dalam Standar Terminologi dan diperlukan oleh Slot. Kontrak endpoint Schedule belum ditemukan pada katalog publik snapshot ini.
